# 路线探路模式

## 产品边界

路线探路不是转向级导航，也不替代高德地图。它在路线生成后，把有限的路线走廊采样转成用户可执行的沿途节点，并在用户决定出发前回答四个问题：

1. 沿途是否有会影响行动的天气变化；
2. 路线时间是否与当前拍摄窗口重合；
3. 长距离行程是否存在必要的加油、补给、餐饮、停车或医疗线索；
4. 粗化路线采样段是否存在仍有效的官方关闭、道路管制或限制证据。

实际导航通过高德地图 URI 交接。栖光不维护道路转向、实时路况或导航语音。

## 数据链

```text
高德路线几何
  → 本地 RouteCorridorContext（2–5 个粗化采样）
  → 路线天气
  → Provider Hub：OSM 参考 + 官方公告证据
  → RouteCorridorIntelligence
  → RouteScoutPlan
  → 路线页摘要 / 沿途时间轴 / AI 受约束上下文 / 后台可观测
```

### 沿途天气

- 使用已有 `/v1/route/weather` 接口；
- 每个采样带预计抵达时间和路线进度；
- 雷暴、低能见度、强风及明显降水优先；
- 缓存或部分覆盖必须明确标记；
- 雷暴等信号只提示查看安全卡与官方预警，不由探路模式生成安全行动建议。

### 路线走廊情报

`/v1/route/weather` 以向后兼容方式增加 `corridor`：

- `contractVersion: 1`；
- `coverage`: `full`、`partial` 或 `unavailable`；
- 每段只保留路线进度、预计时间、固定类别计数和证据状态；
- 公开地图参考覆盖停车、加油、餐饮、饮水、厕所、庇护设施、休息区、观景点和历史对象；
- 官方公告只输出固定限制类别、权威状态与事实 ID，不返回原始标题或正文；
- 不返回路线 ID、经纬度或完整路线几何。

公开地图标注不代表营业、开放、可进入或现场安全。具体停车和补给候选仍以客户端高德查询为主，服务端参考不会重复生成用户卡片。

### 官方关闭与管制

只有满足以下条件时，Flutter 才生成路线安全节点：

- `restrictions.status == present`；
- `authoritative == true`；
- 存在受支持的限制类别和事实 ID。

`closure`、`roadClosure`、`fireRestriction` 为 `critical`；`regulation` 和 `eventChange` 为 `high`。节点只说明存在有效官方证据，并要求用户打开官方来源和地图导航确认。

`noneObserved` 只表示本次采样未检出仍有效公告，绝不转换为“道路安全”“道路开放”或“可以通行”。

### 拍摄时间

- 只判断路线时间与当前 `ShootingSession` 是否重合；
- 不把时间重合包装为沿途存在已验证机位；
- OSM 观景点和历史对象只作检索参考，不直接生成摄影机会卡；
- 用户仍需打开机会详情并在现场确认主体、方向和可达性。

### 沿途服务

服务查询按路线长度和预计时长触发，最多四次：

- 驾车且距离达到 50 km：中段查询加油；
- 行程较长：中段查询补给；
- 两小时以上：后段查询餐饮；
- 驾车路线：目的地附近查询停车；
- 极长路线：后段查询医疗。

查询结果是采样点附近候选，不是路线必经点。UI 必须显示近似路线进度，并提示用户在地图中确认。

## 排序规则

节点按以下顺序排序：

1. `critical`：官方道路关闭、防火限制、雷暴等必须先确认的信号；
2. `high`：其他官方限制、低能见度、强风、降水变化、离线路线；
3. `normal`：拍摄时间重合和服务候选。

同一优先级内按路线进度和预计抵达时间排序。计划最多保留 12 个节点，地图最多显示 6 个服务标记，避免信息过载。

## 行程中界面

未开始时显示探路结论、重点数量和数据覆盖状态。开始行程后进入安静模式：

- 只显示下一条尚未经过的重要节点；
- 不持续展示完整列表；
- 用户主动点击“探路”才展开时间轴；
- “导航”直接交接给高德地图；
- 探路加载失败不阻塞路线或外部导航。

当前进度仅根据行程开始时间和路线预计时长估算，不声称为实时道路位置。

## AI 上下文与隐私

AI 不接收原始路线几何。Context 快照写入 ContextSnapshotStore 时，仅保留每个走廊采样所在约 5 km 网格的中心点、预计时间和进度。服务端使用粗采样获取短期天气、公开地图参考和官方公告证据，再写入有边界的 `contextFacts` 与机器可读覆盖状态。

- 原始 GPS 和完整折线不进入对话历史；
- 路线天气最多保留 30 分钟有效期；
- 官方公告原始标题、正文和精确位置不进入 AI 上下文；
- 安全与拍摄计划的确定性回答不会触发不必要的路线请求；
- 路线情报失败只减少上下文，不阻塞 AI；
- 高德服务候选不进入模型，避免模型把附近候选误说成必经点。

## 可观测边界

后台“数据可观测”增加路线情报指标：

- 请求与可用率；
- 采样段覆盖率；
- 存在停车、补给和摄影语义参考的段数；
- 官方限制存在、未检出和不可用的段数；
- 权威限制与已核验证据数量。

统计不保存路线 ID、精确坐标、地点名称、公告正文或完整路线几何。

## 降级策略

1. 路线天气不可用：仍显示拍摄时间和可用服务候选；
2. 官方公告不可用：显示证据不可用，不生成安全或开放结论；
3. 公开地图不可用：继续使用客户端高德服务候选；
4. 服务查询不可用：读取 24 小时内匹配当前路线指纹的本地缓存；
5. 全部增强链不可用：保留路线、预计抵达时间和外部导航；
6. 离线路线：明确提示道路和耗时可能变化；
7. 探路模式不改变 Context V5 的安全事件与机会判定权限。
