# LumaNest 局域网管理后台设计

## 目标

为 NAS 上的 LumaNest 数据代理增加一个只允许局域网访问的 Web 管理后台，使管理员无需编辑 `.env` 或频繁重启 Docker，即可替换第三方 Key、测试连接、调整安全范围内的运行参数并执行有限维护操作。

后台密码的目的仅是阻止未授权访问。用户登录后可以直接修改、测试和保存配置，不要求二次输入密码，也不增加 TOTP。登录状态保持 30 天，除非主动退出、修改密码、清除浏览器数据或管理员使全部会话失效。

## 访问与认证边界

- App API 继续监听 `8787`，只提供 `/v1/*` 与健康检查。
- 管理后台使用独立监听端口 `8788`，页面使用 `/admin/*`，管理 API 使用 `/admin-api/*`。
- 路由器反代只连接 `8787`，不得转发 `8788`。管理入口固定为 `http://NAS_LAN_IP:8788/admin`。
- 管理请求还必须来自私有局域网地址，作为第二层保护；第一版不信任任何转发头，避免伪造 `X-Forwarded-For`。
- 当前反代运行在路由器上，公网请求到 NAS 时会呈现为路由器私有地址，因此不能只靠来源 IP 或同端口路径隔离。独立端口是 LAN-only 的主要网络边界。
- 使用单管理员密码。密码采用 Argon2id 哈希，不保存明文。
- 登录成功后签发随机、不透明的 30 天会话 Cookie；Cookie 使用 `HttpOnly`、`SameSite=Strict`，HTTPS 时附加 `Secure`。
- 登录失败按来源 IP 限流；修改密码后所有旧会话失效。
- 忘记密码只能在 NAS 本地使用维护命令重置。

## 配置存储

当前环境变量继续作为首次启动和兼容回退来源。后台保存过的配置写入独立持久化卷 `/var/lib/lumanest`，优先于环境变量。

- 敏感字段使用 AES-256-GCM 加密后保存。
- 配置加密主密钥通过 Docker Secret 或环境变量注入，不写入配置库。
- 管理页面永不返回完整 Key，只显示“未配置”或末尾四位掩码。
- Key 更新是覆盖写入，不能从后台导出完整值。
- 配置写入使用临时文件和原子替换，防止并发或断电导致半写状态。
- 审计日志只记录时间、操作类型、配置字段名和结果，不记录旧值、新值、请求体或密钥片段。

## 页面范围

### 概览

显示服务状态、运行时间、版本、配置更新时间，以及和风天气、高德、通义千问、Open-Meteo 与 GBIF 的可用状态。

### 密钥与服务

支持覆盖更新和连接测试：

- 和风 Key ID、Project ID 与 Ed25519 私钥
- 高德 Web Key
- 通义 API Key、API 地址与模型
- App 服务访问令牌

测试成功后可保存；用户也可明确选择强制保存。测试和保存失败不能替换当前有效配置。

### 运行设置

- AI 总开关、模型与超时
- 野生动物检索半径与缓存时长
- 高程缓存时长与最大采样点
- 路线、POI 与天气请求超时
- 摄影机会最低置信度
- 调试日志开关

每个参数都有服务端最小值和最大值，不能通过前端绕过。

### 安全与维护

- 修改管理员密码
- 查看脱敏登录和配置审计记录
- 清理缓存
- 导出脱敏配置
- 重启服务
- 退出当前会话或全部会话

第一版不提供完整 Key 导出、数据库下载、远程终端或 Docker Shell。

## 保存与生效流程

```text
填写草稿
→ 服务端验证字段和范围
→ 可选第三方连接测试
→ 加密写入临时配置
→ 原子替换正式配置
→ 更新内存配置快照
→ 写入脱敏审计记录
```

运行时请求从原子配置快照读取当前值。保存成功后，新请求立即使用新配置，不需要重启容器。进行中的请求继续使用旧快照，避免中途切换。

启动顺序：

```text
读取配置加密主密钥
→ 打开持久化配置库
→ 读取后台配置
→ 缺失字段回退到现有环境变量
→ 启动 App API 和管理后台
```

## 错误处理

- 无法读取或解密持久化配置时，拒绝覆盖写入并继续使用有效环境配置；状态页显示维护告警。
- 新 Key 测试失败时保留旧 Key，错误只表达认证失败、超时、上游不可用或格式错误。
- 错误响应和日志不得包含请求头、请求体、完整上游响应、Cookie、会话令牌或 Key。
- 原子保存失败时旧配置文件保持不变。
- 管理后台异常不得影响 `/v1/*` 的可用性。

## 测试与验收

自动化测试覆盖：

- 公网来源无法访问管理页面或管理 API
- 未登录请求被拒绝
- 登录 Cookie 属性、30 天有效期和会话失效
- 密码哈希与登录失败限流
- Key 不出现在 HTML、API、日志、错误或审计记录
- 配置加密、解密、原子替换和重启恢复
- 保存失败时旧配置继续生效
- 并发保存不会损坏配置
- 运行设置的服务端范围校验
- 现有 App API 全量回归

NAS 验收覆盖：

- 通过 `http://192.168.100.151:8788/admin` 登录
- 从同一局域网修改并测试配置
- 保存后无需重启即可用于新请求
- 容器重启后配置保持
- `8787` 不提供 `/admin` 和 `/admin-api`
- 公网反代域名无法连接 `8788`
