# LumaNest V1 P1 体验修复设计

## 范围

本轮只修复 2026-07-16 真机审计确认的三个 P1：路线地图加载期间无反馈、路线空态主按钮与实际流程不一致、灵感无事件状态过度留白。不改变情境规则、路线数据、AI 边界、五页导航或整体视觉语言。

## 方案选择

### 路线地图

选择在现有高德平台视图上增加本地加载覆盖层。地图创建前显示固定高度、可读的加载状态；超过八秒后改为“地图加载较慢，可先查看文字路线”，但不阻塞路线步骤、距离和安全信息。平台视图创建完成后移除覆盖层。离线路线提示继续保留。

没有选择静态地图缩略图，因为它需要新增图片接口、缓存和授权边界；也没有把地图改为按需展开，因为这会改变当前路线信息架构。

### 路线入口

空态主按钮从“创建路线”改为“去探索选目的地”。动作仍进入探索页，保持现有真实数据流和最近路线逻辑；辅助文案继续说明 GPX 导入能力。

没有在本轮增加路线页内搜索，因为探索页已经提供地点、机位、补给和路线交接，重复搜索会扩大状态同步范围。

### 灵感空态

无可靠创作事件时继续不生成纸条。空态从整页居中提示改为顶部紧凑行动卡，明确“规则尚未成立”，并提供唯一动作“去探索附近”。有事件时瓶子、抽取、执行和收藏完全不变；安全事件仍不进入灵感瓶。

## 状态与错误处理

- 地图覆盖层只描述渲染状态，不修改路线加载状态。
- 八秒慢加载提示不宣称失败；路线文字内容始终可用。
- 灵感空态动作只导航，不刷新或制造事件。
- 没有路由容器的 Widget 测试可注入空态动作，避免隐式依赖。

## 验证

- Widget 测试覆盖地图初始加载覆盖层和八秒慢加载文案。
- 路线空态测试更新为真实按钮文案，并确认动作仍进入探索。
- 灵感测试覆盖无事件、不出现瓶子、唯一探索动作可触发。
- 运行 Flutter analyze、相关测试、全量测试、格式和 diff 检查。
- 构建配置化 APK，在 Mi 10 Pro 无线真机复测路线模式切换和灵感空态。
