# LumaNest V1 审核后野生动物地图图层设计

## 目标与边界

探索页在用户主动进入“野生动物线索”意图时，可以覆盖经过审核的粗粒度历史观察区域。图层只表达“历史上可能出现”，不表达实时目击、精确栖息地或安全保证。

本轮不下发 GBIF 原始观测坐标，不从区域聚合记录推导热力图，不展示精确敏感物种位置。官方动物风险仍使用独立安全事件通道，在风险数据具备可验证的生效和失效时间前，不生成可关闭的地图风险图层。

## 架构与契约

PostGIS 只查询同时满足以下条件的几何：特征和数据源均启用，许可状态为 `approved`，数据源类别为 `wildlifeHistorical`，证据类别为 `wildlifeOpportunity`，类型为 `protected`，几何为 `Polygon` 或 `MultiPolygon`。查询范围由 WGS84 中心点和 5–50 km 半径构成，限制返回数量，并在数据库内保留拓扑地简化。

FastAPI 新增内部查询，Node Broker 以 App 服务令牌暴露唯一公网入口。返回契约包含版本、生成时间、查询范围和区域列表；每个区域包含稳定 ID、通用名称、GeoJSON 几何、数据源署名、版本和更新时间。敏感区域不返回内部名称或数据源 ID。

## 客户端与降级

Flutter 只在 `ExploreFocus.wildlife` 激活时请求图层。原始几何始终保持 WGS84，绘制到高德地图时逐顶点转为 GCJ-02，不覆盖源数据。图层使用低透明度多边形和固定图例，明确标注“历史观察区域，非实时位置”及署名。

图层请求失败、空结果或几何非法时，地图、POI 和既有 GBIF 区域摘要继续可用；不把失败伪装成“没有动物”。服务端、Broker 和 Flutter 测试需覆盖授权过滤、敏感名称隐藏、非多边形拒绝、坐标转换、意图退出后图层消失和失败降级。

## 离线缓存

图层使用 Drift 保存最多 8 个最近查询结果，每条记录包含 WGS84 查询中心、半径、保存时间、服务端生成时间和经过客户端验证的有界载荷。缓存有效期为 24 小时，仅匹配半径一致且中心距离不超过 5 km 的记录。

在线成功时写入缓存，包括空区域结果，以便已撤销或已禁用的数据不会被旧缓存重新显示。只有网络或响应故障才可回退到有效缓存；配置缺失不允许回退。缓存结果在界面明确标记“离线缓存”。“清除离线环境数据”和“停止并清除”均删除全部图层缓存；清除发生前已启动的请求不得在结束后将数据写回。
