# 摄影环境工作台清晰度验收

摄影环境工作台必须优先回答用户决策，而不是展示内部计算术语。

## 主阅读顺序

1. 直接结论：值得重点关注、出发前再确认，或暂时没有足够数据判断。
2. 候选时段与重点时刻。
3. 最主要的环境限制，例如低云遮挡、能见度偏低、降水可能性较高或阵风较强。
4. 当前有依据的环境事实。
5. 仅在至少存在两个可靠采样点时展示未来窗口对比。
6. 摄影影响解释与数据可靠性边界。

## 展示约束

- 不使用“存在需要现场确认的候选窗口”作为主结论。
- 太阳角度必须标记为“太阳高度”，并说明位于地平线上方或下方。
- 没有足够采样的数据指标不得显示标签、空坐标系或占位图表。
- 趋势图只比较当前与候选窗口峰值，不暗示中间时段连续变化。
- 不在主阅读链路暴露采样总数、内部来源标识或原始缺失来源代码。
- 7Timer 只能表述为交叉核对来源，不能包装为拍摄概率。
- 数据过期、来源缺失或可信度下降时必须明确说明。

## 回归门槛

- 320 px 宽度和 130% 字体缩放无溢出。
- 条件窗口显示直接下一步和主要限制。
- 无未来窗口数据时整个对比区域退场，不保留空白模块。
- Flutter analyze、全量测试、后端服务测试与 Debug APK 构建全部通过。
